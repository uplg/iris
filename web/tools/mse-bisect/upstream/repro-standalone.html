MSE + HEVC open-GOP: a CRA start is dropped silently

Serve this directory over HTTP (python3 -m http.server 8099) and open http://127.0.0.1:8099/repro.html. The three files are produced by make-repro.sh from two open-GOP HEVC Main 10 sources that differ only in B-frame count.

Each row appends an init segment and one media segment to a fresh SourceBuffer, waits for updateend, then reports buffered and how many frames the element actually decoded.
